Privacy Policy

Last Updated: October 2026

This Privacy Policy describes how HaptixUI ("we", "our", or "us") and our automated Instagram service (HaptixUI Bot) handle data when you interact with our website (haptixui.github.io) and our Instagram account.

1. Information We Collect

When you comment on our Instagram reels or posts requesting UI component code links (e.g. keywords like "CODE", "BUTTON", "CART"), we receive publicly available metadata provided by the Instagram Graph API via official Webhooks:

  • Instagram Public Username / User ID (to send direct messages and replies).
  • Comment ID and text content.

2. How We Use Information

We process this information strictly to:

  • Deliver direct messages containing component source code links you requested.
  • Post an automated reply confirming your requested component link was dispatched.
  • Prevent duplicate messaging for repeated comments.

3. Data Retention & Storage

We do not store your personal information in persistent databases. Public comment IDs are cached temporarily in volatile memory only to prevent spam/duplicate triggers and are cleared automatically. We never sell, share, or monetize any user data.

4. Third-Party Services

Our automation relies on the official Meta Graph API and Instagram Platform. Your use of Instagram is governed by Meta's Privacy Policy.

5. Data Deletion Requests

If you wish to have any temporary logs or interaction records removed, please visit our User Data Deletion Page or contact us directly at sachinmandawi@gmail.com.

6. Contact Us

If you have any questions regarding this Privacy Policy, please email us at sachinmandawi@gmail.com.
